# Prototype walkthrough script

Target duration: about 100 seconds.

| Time | Screen | Narration |
|---:|---|---|
| 0-8 s | Logo and positioning | "PatientTriage.ai is a safety-first emergency coordination prototype. It is not an ERP, diagnosis tool, or replacement for a clinician." |
| 8-22 s | Nurse 18-bed view | "A nurse sees all 18 district emergency care spaces. Green is available; occupied beds use acuity colors. Select a bed for the current patient, wait, and monitoring state." |
| 22-36 s | Patient-wise queue | "The same workload can be reviewed patient-wise. Safety rules establish the floor; CDM context orders within that floor, while confidence and missing information stay visible." |
| 36-50 s | Deterioration | "When a waiting patient's observations worsen, the queue is recomputed and the system explains why review priority changed." |
| 50-62 s | Doctor override | "The doctor remains in control. Every override requires a reason and is appended to the tamper-evident audit chain." |
| 62-75 s | Pharmacy and blood-bank views | "Support teams receive only minimum-necessary readiness signals. These are acknowledgements, not inventory, ordering, or dispensing functions." |
| 75-88 s | Administration and baseline chart | "Administration sees capacity, staffing assumptions, surge controls, and a transparent comparison against FCFS, acuity, SJF, waiting, and combined baselines." |
| 88-100 s | Tests and roadmap | "The package includes 159 automated tests at this checkpoint, Docker and virtual-environment setup, technical and business documentation, regulatory mapping, and a measured scale path." |

The generated video uses synthetic dashboard visuals and does not show real patient data.
